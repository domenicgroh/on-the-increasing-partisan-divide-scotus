# Data

This directory contains the source data required to reproduce the analyses.

The analysis uses:

- Case Salience Index, 1953–2014
- Case Salience Index, 2015–2024
- Supreme Court Database, Justice-Centered Citation-Organized dataset, 2025 Release 01

The required filenames are:

- `CSI-1953-2014.xls`
- `CSI_2015-2024.zip`
- `SCDB_2025_01_justiceCentered_Citation.csv_.zip`

Source and licensing information will be added before public release.
