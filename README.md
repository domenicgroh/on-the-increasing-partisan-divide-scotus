# Replication materials for "On the Increasing Partisan Divide of the U.S. Supreme Court"

This repository contains the replication materials for the paper
**"On the Increasing Partisan Divide of the U.S. Supreme Court."**

The repository includes the complete analysis code, a rendered analysis PDF,
and documentation for the source data used in the study.

## Repository contents

- `Analysis.qmd` — Quarto/R source file containing the complete analysis.
- `Analysis.pdf` — rendered version of the analysis.
- `data/` — documentation and, where redistribution permits, source data used in the analysis.
- `figures/` — figures generated by the analysis.
- `tables/` — tables generated by the analysis.
- `analysis_data/` — derived datasets generated during the analysis.

## Data sources

The analysis combines three principal data sources:

1. The Case Salience Index covering 1953–2014.
2. The updated Case Salience Index covering 2015–2024.
3. The Supreme Court Database, 2025 Release 01, Justice-Centered Citation-Organized dataset.

See `data/README.md` for source information, required filenames, and data-use information.

## Reproducing the analysis

The main analysis is contained in:

`Analysis.qmd`

The analysis is written in R using Quarto.

Required input files should be placed in the `data/` directory using the filenames specified in `data/README.md`.

The analysis creates output in the following directories:

- `figures/`
- `tables/`
- `analysis_data/`

The analysis covers U.S. Supreme Court October Terms 1953–2024.
